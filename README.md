# XAFSmass 离线网页版

直接用浏览器打开 **XAFSmass.html** 即可使用。单文件约 8 MB，内含计算代码、材料预设及散射因子数据库，不需要 Python、服务器或网络。分享时只需发送这个 HTML；若聊天工具不支持打开 HTML，请先保存到电脑再用浏览器打开。

## 保留的修改

- 以你上传的修改版界面为准：浅灰蓝背景、白色输入框、蓝色主按钮与结果文字。
- 保留 component / 比例 % / matrix 三栏、只读组合配方、默认基体纤维素 C6H10O5、默认面积 0.3848 cm²、默认能量 9029 eV、Chantler total 数据表。
- 原始 wt% 配方始终保留；内部沿用修改版脚本的三位有效数字原子系数转换。
- 保留底部总吸收、边跃和 MEX-1 参数参考文字。
- 支持粉末、箔片/薄膜、气体、未知含量四种模式；气体分压混合器、f′/f″ 绘图、范围调整、图片保存和 CSV 导出。
- 浏览器初始显示 Cu、μₜd = 1.5 的演示计算。此默认演示是网页新增，原脚本这些输入为空。

## 例子

计算能量定义为 **E = edge + 50 eV**。吸收边快捷选择会自动加 50 eV，例如 Fe K：7112 → 7162 eV，Cu K：8979 → 9029 eV。能量输入框显示最终计算能量；手动输入时请直接填写加完 50 eV 的值，程序不会再次加 50。

粉末混合物：组分 `LiNi0.5Co0.2Mn0.3O2`，比例 `6`，基体 `C6H10O5`，能量 `8383` eV（Ni K edge 8333 + 50）。组合配方显示为 `(LiNi0.5Co0.2Mn0.3O2)%6(C6H10O5)`。

纯物质：组分 `Cu(NO3)2`，比例留空。此时基体不参与计算。

气体混合器：选择气体模式，组分填写 `(Ar)(N2)`，比例留空；下方显示分压滑块。混合器结果独立显示，主结果仍按上方配方和目标吸收比例计算。

未知含量：选择未知含量模式，组分 `FexSiO2`，比例留空，能量 `7162` eV（Fe K edge 7112 + 50），总吸收 `1`，目标边跃 `0.1`。

## 与上游的明确差异

1. 修正 `calculate_x` 的质量百分比分母：上游在循环结束后引用了最后一个元素 `e`，应使用未知元素本身。网页版采用 `m_x / (m_matrix + m_x)`；未知含量结果不承诺与有此错误的原函数逐字一致。
2. 参数无效、wt% 合计达到 100%、未知含量不可达时显示错误，不自动取绝对值或夹到零。0% 或 100% 请改为直接填写对应纯组分。
3. BrCo 原数据中 H、He 表为空，网页会提示更换数据表，不生成替代值。
4. 带 wt% 配方仍按原界面进行三位有效数字转换；这会带来微小的实际质量比例舍入差异。
5. 保留原边跃搜索逻辑及固定气体温度 295 K。气体通量沿用原电离室估算模型；未知含量误差估计也沿用原公式。这里验证的是移植一致性，并非对这些原模型进行重新标定。
6. 绘图采用浏览器 Canvas，支持能量范围、双轴和 PNG 保存；不包含 Matplotlib 的全部工具栏功能。

## 验证

共 122 个场景：111 个主计算场景（其中 1 个不可达边跃应报错），11 个气体混合场景。823 项数值比较通过，最大相对误差 6.03 × 10⁻¹⁶ 以下。粉末/薄膜/气体对照上游 Python；未知含量对照修正分母后的计算式。另通过 19 个无效输入检查。上游缺失数据的案例跳过数值对照，并验证网页报错。

Microsoft Edge 无头浏览器在断网模式直接打开本地 `file://` 文件，检查四种模式、wt% 原文、CSV 下载、f′/f″ 绘图、分压滑块、错误清空、重置。未出现 JS 错误或外部网络请求。检查 1280×1000 桌面布局和 390×844 手机尺寸布局并查看截图。未在真实手机、Safari、Firefox 上实测。

数据源：[kklmn/XAFSmass](https://github.com/kklmn/XAFSmass)，下载日期 2026-10-16。原作者 Konstantin Klementiev、Roman Chernikov。MIT 许可证已完整内嵌在 HTML，源码包也保留许可证。


粉末结果新增组分与基体称量清单：组分质量 = 总质量 × 输入 wt% / 100，基体为余量；比例留空时基体不参与计算，质量为 0。默认基体显示为纤维素（C6H10O5），自定义基体显示实际化学式。总质量旁原物质的量卡片改为压片推荐总质量：7 mm 直径推荐 40 mg，13 mm 直径推荐 90 mg；此参考不改变吸收计算的总质量。

吸收边改为两级选择：元素下拉按原子序数排列，显示原子序数、元素符号及 K 边能量；选中元素后展开其实际有数据的吸收边单选项，并默认选择 K 边。点击其他边后，E 自动更新为该边能量 +50 eV；手动编辑 E 会取消吸收边勾选。
粉末和薄膜结果新增独立 Edge Step（Δμd）数值卡片，优先显示吸收边选择器中的元素；该元素不在配方内时，显示配方中边跃最大的元素并明确标注。各元素完整边跃仍保留在明细表，突出显示的边跃及元素也写入 CSV。
显示样式：称量清单使用浅蓝底色、加粗标题和放大的蓝色质量数值；元素明细中与 Edge Step 卡片对应的计算元素整行加粗并以浅蓝色突出。两个结果表的表头与所有数据均左对齐。
结果强调样式统一：总质量、Edge Step、组分质量、基体质量统一使用 24px、700 字重、深蓝色数值及相同浅蓝底色；说明文字统一灰色，压片推荐用量使用灰底次要提示。保留两个表格左对齐和当前计算元素整行加粗。
